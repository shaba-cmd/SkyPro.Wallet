# Skypro.Wallet

Приложение для учета личных расходов: таблица расходов, добавление нового
расхода и анализ трат по категориям за выбранный период.

**Демо:** [Skypro.Wallet ](https://sky-pro-wallet.vercel.app)

## Стек

React 19, TypeScript, Vite, React Router, CSS Modules.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## Страницы

| Путь                | Что на странице                                |
| ------------------- | ---------------------------------------------- |
| `/login`            | Вход                                           |
| `/register`         | Регистрация                                    |
| `/`                 | Мои расходы: таблица и форма нового расхода    |
| `/new`              | Новый расход              |
| `/analytics`        | Анализ расходов: календарь периода и диаграмма |
| `/analytics/period` | Выбор периода             |

## API

Данные хранятся на сервере `https://wedev-api.sky.pro/api`
